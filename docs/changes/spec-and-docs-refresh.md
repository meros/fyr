# V0.spec-and-docs-refresh: restate SPEC 3 and 5.12 from the code, refresh README and docs, and decouple agycli from claudecli

→ SPEC 3.13–3.17, SPEC 5.12 (#455), V0.one-tool-vocabulary, V0.changes-code-only, V0.old-routes-end, V0.public-repo, decision 0035.

A code and documentation review of the 18–21 Nov changes found SPEC 3.13–3.17, SPEC 5.12, `README.md`, `docs/API-v0.md`, `docs/HOST-SETUP.md`, `docs/PLAN.md`, `docs/decisions/README.md` and `web/NOTES.md` behind the code, plus one cross-adapter import (`internal/cli/agycli` importing `internal/cli/claudecli` solely for `Plain`).

1. **SPEC 3.13–3.17 and 5.12 restated (#455).** The Agent tools table in SPEC 5.12 now matches the registered MCP tools in `internal/engine/` (dropping removed `change_revise`, `change_status`, `change_attach`, `change_unchanged` and documenting `ask`, `run_request`, `change_update`, `pr_create`, `settle_request`, `keep_process`, `project_setup`, `host_setup`, and the 12/hour `thread_new` limit). Front-wide state and the host resource guard's ephemeral runtime state are explicitly named as exceptions to SPEC 5.1. SPEC 3.13–3.17 match code-only changes, worktrees, project policies, dual CLI adapters (`claude` and `agy`) and Decision 0031 path routing.
2. **README and docs updated.** `README.md` and `docs/INSTALL.md` reflect Antigravity (`agy`) support, the Linux desktop app (`fyr-desktop`), multi-PR tracking, trans-host handover, the per-project approval judge, question-card cancel/skip, quota waits and versioned release channels. `docs/API-v0.md` adds native push owner-socket routes, `GET /api/setup`, `host.setupFix`, `thread.wakeOnQuota`, `ThreadDTO.prs`, `provider.login*`, host helper reads and modern `peerPort` NixOS setup. `docs/HOST-SETUP.md` removes private host/config names (`V0.public-repo`) and updates `GET /api/load` to `/api/h/<hostId>/load`. `docs/decisions/README.md`, `docs/PLAN.md` and `web/NOTES.md` match current status.
3. **CLI seam & phone parity cleanup.** `Plain` (ANSI stripping for interactive login parsing) moves to `internal/cli/plain.go`, removing `agycli`'s import of `claudecli`; `provider.Registry.ListModels` uses `cli.Listing` directly instead of `claudecli.Listing`; the phone composer placeholder now reads `"Message…"` to match desktop and support non-Claude providers.

Tests: `internal/cli/plain_test.go` (`TestPlain`), `docs/changes_test.go`, `make test`.
