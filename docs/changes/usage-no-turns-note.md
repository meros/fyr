# V0.usage-no-turns-note: Settings → Usage says when a range holds no agent turns

→ V0.usage-page. The "Fyr's own calls" footer gives their share of the range's tokens. A range that holds only those calls (a fresh host whose first run measured the fixed context, V0.usage-overhead) read "100 %" with nothing to explain it, which looked like a wrong sum. (1) When Fyr's own calls are all of the range's tokens, the footer adds "No agent turns in this range." (2) The page is one component for both fronts, so both show it; the sum itself was right and is unchanged.
