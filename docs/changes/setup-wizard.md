# V0.setup-wizard: live host setup checks (GET /api/setup), Tailscale Serve and gh fixes, and the desktop + phone setup wizard

→ decision 0037 (#434, step 4); also serves Linux without Nix (#199).

1. **Live host checks (`internal/setup`, `GET /api/setup`).** Every step is derived from the host's real state, never a stored "done" flag: (1) This Mac / This machine (macOS 13+, Xcode Command Line Tools / `git`, >= 2 GB free disk), (2) Claude (`claude` CLI and a ready provider), (3) GitHub (`gh` present and signed in with `repo` scope), (4) First project (projects set up, else scans `~/git`, `~/code`, `~/src`, `~/Developer` for git repos), (5) Phone (optional: Tailscale Serve on 7443 or LAN TLS), and (6) Other installs (optional: paired installs and discovered candidates).
2. **Owner-only fix command (`host.setupFix`).** Routed down the one command path (`core.KindHostSetupFix` → `engine.SetupFix`): `clt` (`xcode-select --install`), `gh.install` (downloads official `gh` into `<data>/tools/gh`, which `fyrd` puts on `PATH` at start), `gh.login` / `gh.loginCancel` (device-code login surfaced in the page), `gh.repos`, `project.clone` (clones `owner/name` into `~/git/<name>`), and `tailscale.serve` (`tailscale serve --bg --https=7443`, moved into `fyrd`).
3. **Desktop and phone wizard (`web/src/setup.ts`, `web/src/setup-ui.tsx`, Settings → Setup).** When required steps are not ready, a `"Set up · X of 6"` card appears atop the inbox on both desktop and phone and opens **Settings → Setup**. The wizard runs each fix inline, pairs a phone via the existing QR link (`authAct("add")`), and starts a ready-made first thread on a picked or cloned repo.
