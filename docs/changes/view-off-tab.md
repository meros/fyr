# V0.view-off-tab: turning the live view off removes the View tab

→ amends V0.37. Fyr keeps the last page and state of a view that was turned off, so the client still found a page and kept the View tab (and the view's headline in the inbox row). The client now reads a view only while the thread's `liveView` is on; turning it back on shows the kept page again.
