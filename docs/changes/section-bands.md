# V0.section-bands: a section header is a band, so its rows read as its own

→ V0.section-heads. *Amends V0.section-heads (1): bold type alone did not set a header apart from the rows, whose titles are larger and as bold.* (owner, 19 Nov, about the list: "Balance between headers and items are not clear... It's hard to see what belongs to what category")

(1) **The band.** A header whose section has rows is drawn as a band across the list: a sunken background with rounded corners, the title inside it. A row has no background at rest, so a band is never taken for a row.

(2) **The air.** There is more space above a band than below it, so a band sits with the rows after it and apart from the rows before it.

(3) **Empty sections.** A section with no rows has nothing to hold: no band, the faint line of V0.section-heads.

(4) **Both fronts.** The same rule on the desktop and the phone. The phone's header keeps its 44 px for the finger; the band is drawn inside it.
