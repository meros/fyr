# V0.run-cards-stay-put: a Run card stands where it was first asked and never moves

→ V0.run-cards-in-conversation. *Amends (1) and (2): the card moved to the newest place when asked again, and a card with no place in the loaded log stood at the end, under newer messages, so it looked stuck at the bottom.*

(1) **One place.** A request's card stands where `run.requested` first named it, on the desktop and the phone. Asking the same id again keeps the card there.

(2) **No place in the log.** A request asked before this version, or further back than the loaded part of the log, stands before the loaded messages (under "Show earlier messages"), not at the end. It is the first stop for the "Needs you" jump.

(3) **What waits is in reach.** A request that waits for the owner stands in the dock above the composer, which is the one place to press; Show in conversation scrolls to its card.
