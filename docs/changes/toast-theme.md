# V0.toast-theme: the toast follows the theme, on both fronts

The toast (`.toast` on desktop, `.m-toast` on the phone) was inverted. It was dark (`--night`) in light mode and lighter (`--select`) in dark mode. In light mode its Undo showed as a blank white pill, because the raised-button face in `warm.css` is a background image that outranked the toast's override, under light text. The toast now uses the theme's raised surface with `--ink` text and a `--line-strong` border in both themes. It is light in light mode and dark in dark mode, with its lift shadow. Its Undo is an ordinary button; the phone's `.tb` takes the same ink, and the `--sunken` well when pressed. This replaces the per-theme overrides of V0.toast-dark, V0.toast-pressed-colors and V0.toast-undo-face. The design system's `.fy-toast` (`design/system/components/bundle.css`, generated by `design/generators/make_ds.py`) changes the same way, so the design no longer calls for an inverted toast. The error toast keeps its signal colour.
