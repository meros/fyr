# V0.copy-attach-margins: Copy under a message is quiet text, and the phone attach button sits evenly in the field

The Copy button under an agent message was a bordered pill taller than the run line it sits beside, so the two rows did not line up. It is now text in the run line's type, 20 px high, and shows its box only on hover. On the phone, the attach button was 40 px wide in a 44 px tall slot, so the margin to the field was uneven; it is 44 x 44, with the same margin on every side.
